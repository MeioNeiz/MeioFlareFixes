# Meio FlareFixes

Fixes a FlareUI bug: right-clicks on the bank, a vendor or a quest window opened the chat tab menu.

![A vendor over the chat tabs: before, right-clicking Refreshing Spring Water opens the chat tab
menu; with Meio FlareFixes, the click reaches the item and its tooltip shows](docs/before-after.png)

## What it does

Needs [FlareUI](https://www.curseforge.com/projects/1718307). After you used FlareUI's Meter
tab, the invisible click areas of its chat tabs could stay on top of windows such as the bank,
vendors and quests. Clicks there went to the chat tab instead of the window.

- Bank, vendor, quest and other windows over the chat take their clicks again
- Chat tabs work as before
- During a fight it waits and catches up when the fight ends

No settings, no slash commands. Once FlareUI fixes this itself, Meio FlareFixes does nothing.

## Install

Use your addon manager (CurseForge, Wago), or unzip a GitHub release into
`World of Warcraft\_forever_\Interface\AddOns` and restart WoW fully.
